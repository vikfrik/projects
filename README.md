# Проекты

| Название | Сфера | Основные этапы | Стек |
|:---:|:---:|:---|:---|
| [Формирование модели монетизации для мобильной игры](./game_monetization) | Игры | Задача исследования - сформировать новую модель монетизации мобильной игры Space brothers | `Python`, `Pandas`, `NumPy`, `Matplotlib`, `Plotly`, `Seaborn`, `Scipy` |
| [Анализ результатов A/B теста](./ab_test) | Покупки на сайте | Задача - провести оценку результатов A/B теста, используя данные с действиями пользователей, а также ТЗ. | `Python`, `Pandas`, `NumPy`, `Matplotlib`, `Plotly`, `Seaborn`, `Scipy` |
| [Books vs Covid / SQL](./books_sql) | Стартап | Задача - проанализировать базу данных. В ней — информация о книгах, издательствах, авторах, а также пользовательские обзоры книг. | `Python`, `Pandas`, `SQL`, `sqlalchemy` |

  Пока здесь размещёны:
  - t-invest (исследование в python + описание в pdf) - разведочный анализ данных (EDA), который был сделан на основе датасета [dano](https://dano.hse.ru/data2024) (Т-Инвестиции). В результате предобработки данных и анализа корреляций были выдвинуты основные гипотезы, которые могут быть проверены в ходе дальнейшего исследования.
  - ab_test - проект по a/b тестам: проверка гипотезы, что добавление в лендинг с оформлением дебетовой карты (https://www.tinkoff.ru/cards/debit-cards/tinkoff-black/) информации о дополнительных кэшбеках приведёт к росту конверсии из переходов на лендинг в оформление дебетовой карты.
  - health_case - отборочный кейс по аналитике от School of Analytics. Задача заключалась в анализе и выявлении закономерностей в поведении отдельных категорий клиентов по продлению подписки на сервис, помогающий вести здоровый образ жизни
  - mobicar_case - кейс в сервисе по каршерингу, суть которого заключается в выявлении причины, по которой упала конверсия от захода на лендинг до первой поездки. Известно, что недавно было обновление в поиске, иных изменений не было.
