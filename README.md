# Проекты

| Название | Сфера | Основные этапы | Стек |
|:---:|:---:|:---|:---|
| EDA (t-invest) | Инвестиции | Задача - провести разведочный анализ данных (EDA), который был сделан на основе датасета [dano](https://dano.hse.ru/data2024) (Т-Инвестиции) и выдвинуть основные гипотезы, которые могут быть проверены в ходе дальнейшего исследования.| `Python`, `Pandas`, `SciPy`, `Seaborn`, `Matplotlib` |
| Проведение A/B теста (ab_test) | Банкинг | Задача - проверить гипотезу, что добавление в лендинг с оформлением дебетовой карты (https://www.tinkoff.ru/cards/debit-cards/tinkoff-black/) информации о дополнительных кэшбеках приведёт к росту конверсии из переходов на лендинг в оформление дебетовой карты. | `Python`, `Pandas`, `SciPy`, `Matplotlib`, `Seaborn` |
| Отборочный кейс по аналитике от School of Analytics (health_case) | Здоровье | Задача заключалась в анализе и выявлении закономерностей в поведении отдельных категорий клиентов по продлению подписки на сервис, помогающий вести здоровый образ жизни | `Python`, `Pandas`, `Matplotlib` |
| Кейс по исследованию проблем с воронкой продаж (mobicar_case) | Каршеринг | Задача - выявить причину, по которой упала конверсия от захода на лендинг до первой поездки. | `Python`, `Pandas`, `NumPy`, `Matplotlib`, `Plotly`, `Seaborn`, `Scipy` |
